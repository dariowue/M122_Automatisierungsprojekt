# M122 Automatisierungsprojekt - Einleitung
Dieses Automatisierungsskript für den Onboarding-Prozess von neuen FormsHub-Tenants wurde im Rahmen der Projektarbeit der Berufsschule im M122 umgesetzt.

---

## Projektabgabe
Dieses GitHub-Repository beinhaltet zwei Versionen des Skriptes: Eine normale Version sowie eine Version mit Inline-Kommentaren, die beschreiben, was die Funktionen ausführen, um anderen Mitarbeiter/innen zu veranschaulichen, was genau ausgeführt wird. Zusätzlich sind zwei Exporte des Flowcharts in diesem Repository vorhanden: Einer ist im PNG-Format, der andere im SVG-Format. Da das Flowchart eher umfangreich geworden ist, empfehle ich, das SVG-Format im Browser anzusehen, um keinen Qualitätsverlust zu haben. Das Video sowie der Link zu diesem Repository wurde mit der Teams-Aufgabe abgegeben.

---

## Hinweise
* Dieses Repository wurde nur zur Projektabgabe erstellt und beinhaltet deshalb nur die finalen Versionen ohne jeglichen Versionsverlauf.
* Jegliche Credentials wie TenantId, ClientId und ClientSecret wurden aus Sicherheitsgründen mit beliebig vielen Asterisken (*) ausgetauscht.
* Alle internen E-Mailadressen wurden aus Sicherheitsgründen durch "mail@${env}.internal.com" ersetzt.
* Zusätzlich wurden aus Sicherheitsgründen User-, Kunden- sowie Gruppennamen entweder vollständig oder teilweise abgeändert.
